진행 방식

P-1 읽기 전용 표시부터 검증 → P-2 쓰기(시작 · 투입 · 완료)는 테스트 환경에서 재고 · LOT · 회계 반영 확인 뒤 운영. 기존 생산관리 화면은 파일럿이 끝날 때까지 유지.

분리이유
품목 마스터 ↔ 원재료·제품 기준정보정체성 정본 vs 수량 세계 물리 키
생산계획·지시 ↔ 생산실적의도 vs 결과 기록
배합·BOM ↔ 실제 원재료 투입기준정보 vs 투입 기록(LOT·수량)
입고·출고 ↔ 실사·조정조정은 재고를 직접 바꿈 — 별도 권한·승인
CCP 기록 작성 ↔ 검토·승인작성자·검토자·승인자 분리
매출 등록 ↔ 매출 확정확정 시 재고 차감·분개
회계 제외(B2C) ↔ 회계 포함 매출이중 회계 방지
회계 전표 ↔ 재고 수불 원장서로 다른 정본

권한

메뉴 표시는 권한이 아니다. 서버가 테넌트 · 역할 · 대상 데이터 소유권 · 업무 상태를 함께 검사한다. 기존 권한표는 검증된 적이 없으므로 재검토 뒤에만 적용한다 (품질검토자의 회계 승인, 회계 담당자의 재고 수정 제거). 작성 · 확정 · 취소 · 역분개는 별도 권한.
