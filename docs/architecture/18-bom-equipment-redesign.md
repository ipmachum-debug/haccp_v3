## 1. 분석 요약 — 지금 있는 그대로

### 1-1. 설정 화면 (생산까지 17단계, 마법사 없음)
가입 → 업종 → 회사정보 → 부서·직급·구성원 → 문서결재 → 기능 스위치 → 카테고리 → 거래처 → 품목·SKU → 중간재 → **설비** → **공정 그룹(한계기준·설비 배정·시간)** → **품목제조보고** → 승인 → 공정-제품 수동 연결 → 체크리스트·일지 설정 → 생산.
- 가입 때 업종을 묻지 않는다 (`OnboardingPage.tsx:69`). 업종 플러그인은 메뉴·라벨만 정하고 기본 데이터를 넣지 않는다.
- 같은 것을 설정하는 화면이 여러 곳: 품목 4 · BOM 4 · 한계기준 3 · 거래처 2 테이블 · 회사정보 2 · 체크리스트 템플릿 3.
- 설비 마스터의 실제 화면은 'CCP 모니터링 > 설비기준' 탭. `EquipmentManagement.tsx` 는 경로 없음, 시간 프로필(`ccp_time_profiles`)은 화면 없음.
- 품목제조보고를 **승인하지 않아도 배치가 만들어지고**(최신 초안 사용), 보고서가 없으면 원료 투입 없이 조용히 넘어간다.
- 화면 용어: CCP-1B·CCP-4P, time_min, 묶음 순차, 배치 간격, 원물·공정 기준, 전처리 배율, 환산율(구매→기본), DAILY_LOG_V2 …

### 1-2. 재료 흐름
```
입고(포장 환산 1단계) → LOT → [품목제조보고 → 버전 → 원료 줄]
  → 배치: 투입 계획 (이전: 배합비 % × 완제품 kg / 수율 기준: 원물 스냅샷)
  → 자동 출고 (업무일 기준, 소비기한 빠른 LOT) → 완료 → 완제품 LOT → 출고·매출 → 분개
```
- **원료 필요량 계산식이 5곳** (배치 생성 · 미리보기 · 배치 요구량 · 공정 보정 배합 · BOM 화면). BOM 화면에서 본 값 ≠ 실제 차감 값.
- **kg 단위 원료 줄을 % 로 계산** (`batchCRUD.ts` 이전 방식 `ratio/100 × 생산량`, 단위 무시) — 단지 찹쌀떡(떡마루)·흑임자인절미 승인 버전 17줄. *(운영 영향 Codex 확인 필요)*
- **정제수 = 원료 번호 191 고정** (`mfReportCalculation.ts:444`) — 회사 전용 값. 물 판단이 3가지(차감 여부 칸·재고 제외 표시·이름 '정제수').
- 버전: 승인된 버전을 그 자리에서 고칠 수 있음, 새 버전은 원료 없이 생김, 수정은 최신 버전·생산은 최신 승인 버전.
- BOM 원료 → 재고 원료를 **이름 일치**로 잇는 곳이 남아 있음 (`batchCRUD.ts:208-233` — 정체성 정책 위반).
- 중간재 저장 방식 4가지, 중간재만 있는 줄은 계획·차감에서 빠짐.
- '1회 기준' 비슷한 숫자 3개 (1회 기준량 `batch_target_kg` · 기준 완제품량 · 수율조정 중량 합계), 물 뺀 % 따로 저장, 수율 스위치 2개(회사+버전).
- 단지 실제: 원료 줄 1,183 중 % 1,143 · 전처리 배율 1줄 · 수율 기준 켜진 버전 1개 · **공정 미지정 247줄**.

### 1-3. 설비 흐름
```
설비(평상값) → 공정 그룹(한계기준·운전 방식) + 설비 배정 + 시간 프로필(화면 없음)
  → 제품의 공정 = BOM 원료 공정 지정 + 제품 수동 연결 + 금속검출 항상
  → 하루 계획: 회차 = 총량 ÷ 1회 기준량, 가장 먼저 비는 설비, 시각, 투입량, 평상값
  → CCP 기록지 초안(계획값·평상값·'적합' 미리 채움) → 현장 → 시트 확인 → 승인
```
- **설비 용량 칸 없음** — 큰 설비·작은 설비 같은 kg.
- **공정 순서·합류 데이터 없음** — 공정마다 설비 '아침 시작시각' 에서 따로 출발. 단지는 교반 05:00 · 증숙 08:40 · 오븐 09:00 · 금속검출 08:20 으로 순서를 흉내.
- **미리 채운 값이 실측처럼 통과** — 가열·온도·압력과 **품온(제품 중심온도)까지 설비 값으로 채우고 '적합'**. 값마다 '미리 채움/확인' 구분 없음.
- 시간 설정 5곳(설비 기본 가열 · 1회 사이클 · 시간 프로필 · 한계기준 시간 · 투입 간격), 운전 방식 저장 3곳, 압력 단위 MPa/bar 혼재.
- 현장 기록지에서 운영방식·간격·한계기준을 바꿀 수 있음. 금속검출기는 회사당 1대만.

## 3. 목표 구조 — 3층 + 현장

```
[1층 공장]  공정 · 설비 · 운전 방식 · 평상값 · 용량 · 공정 흐름 틀      ← 고정값, 처음 한 번 (관리자)
     ↑ 참조
[2층 제품]  품목제조보고 → 버전 → 원료 줄 (어느 공정 / 처리 전후 무게)  ← 변동값, 버전 보존
     ↑ 참조
[3층 하루]  날짜 · 제품 · 총량                                         ← 매일 사람이 넣는 건 이것뿐
     ↓ 자동
  생산 배수 → 원료 차감(원물 kg) → 공정 투입(공정 kg) → 회차(1회 기준·설비 용량)
  → 설비 배정·시각(흐름 순서·공유 설비) → 기록 초안(평상값)
     ↓
[현장]  내 공정 오늘 작업 순서 → 정상이면 묶음 확인, 다르면 그 칸만 → 사후 몰아서 확인 가능
```
원칙: 질문에 대답만 · 계산은 시스템 · 평상값 초안 · 예외만 수정 · 같은 걸 두 번 묻지 않음 · 버전 보존 · 실수는 프로그램이 막음.

## 4. 1층 공장 설계 (설비)

### 4-1. 질문 (설정 화면 대신)
| 질문 | 저장 |
|---|---|
| 우리 공장 공정을 고르세요 (업종 틀: 떡류 = 교반·증숙·굽기·금속검출) | 공정 그룹 |
| 이 공정은 가열 공정인가요? 몇 도 이상, 몇 분 이상? | 한계기준 |
| ○○기는 몇 대? 이름은? | 설비 |
| 한 번에 최대 몇 kg 넣어요? | **설비 용량 (신규)** |
| 평소 온도 · 압력 · 가열 몇 분? | 설비 평상값 |
| 한 번 도는 데 (넣고 꺼낼 때까지) 총 몇 분? | 1회 사이클 |
| 여러 대를 동시에 / 한 대씩 차례로 / 몇 대씩 묶어서? | 운전 방식 (한 곳에만) |
| 같은 기계를 다른 공정에도 써요? | 공정-설비 연결 (공유 표시) |
| 공장은 몇 시에 시작해요? | 회사 시작시각 하나 (설비별 시작시각 대체) |
| 모든 제품이 거치는 공정이 있나요? (금속검출 등) | 공통 후속 공정 |
| 이 제품군은 어떤 순서로 만들어요? (그림에서 연결) | **공정 흐름 틀 (신규)** |

### 4-2. 정리
- 시간 설정 5곳 → 사람이 답하는 건 **'평소 가열 몇 분' · '한 번 도는 데 총 몇 분'** 두 개. 나머지(한계기준 시간은 법정 기준, 시간 프로필은 제품별 예외)만 고급 보기.
- 운전 방식은 공정 그룹 한 곳 (기록지 레코드·정책 표는 읽기 전용 복사).
- 압력은 화면·저장 모두 한 단위(bar 또는 MPa, 회사 선택 없이 하나로) — 변환은 한 함수.
- 현장 기록지에서 운영방식·한계기준 편집 제거 (관리자 공장 설정에서만).
- 결과 확인: **공장 지도** (공정 → 설비 → 평상값·용량·운전 방식) 한 장.

### 4-3. 공정 흐름 틀
- 제품군(또는 제품) 단위로 '공정 → 공정' 연결과 합류 지점을 저장. 확인된 것만 쓴다 — BOM 공정 지정으로 순서를 추측하지 않는다.
- 계획 계산: 다음 공정 시작 = 앞 공정(들) 끝 시각 이후 (합류는 모든 앞 공정이 끝난 뒤). 흐름 틀이 없으면 지금처럼 설비 시작시각(안내 문구 표시).
- 금속검출 = 흐름의 마지막 공통 공정 → 굽기·성형이 끝난 뒤 시각.

## 5. 2층 제품 설계 (BOM — 품목제조보고에서 출발)

### 5-1. 질문
1. 품목제조보고 PDF·엑셀 올리기 → 원료·% 자동 읽기 → **확인만**.
2. **"이 배합으로 한 번 만들면 완제품이 몇 kg 나와요?"** → 1회 기준 = 완제품 kg (한 가지 뜻).
3. 원료마다 두 가지:
   - **어느 공정에 넣어요?** → 버튼: (흐름 틀의 공정들) / **공정 없이 바로 넣음(후첨)** / 모르겠음 → '모르겠음'은 준비 점검표에 남음.
   - **넣기 전에 무게가 바뀌나요?** → 아니오 = 1:1 · 예 = "처리 전 40kg 이면 처리 후 몇 kg?" → 배율 자동.
4. 원료 마스터 기본값 상속: "생찹쌀은 불리면 ×1.4" 를 **원료에 한 번** → 그 원료를 쓰는 모든 제품이 물려받음 (다른 제품만 고침). 물·재고 차감 안 하는 원료도 원료 마스터 한 곳.
5. **공정 흐름도 + 시험 계산**: "475kg 이면 → 교반 5회, 생찹쌀 ○○kg 차감, 교반기 투입 60kg씩" → 맞으면 승인 → 버전 잠금.

### 5-2. 계산 하나로
- `원료 필요량(버전, 계획 완제품 kg)` 한 함수 → 원물 kg(차감) · 공정 kg(투입) · 공정별 1회 투입량.
- BOM 화면 미리보기 · 배치 투입 계획 · CCP 투입량 · 시험 계산이 모두 이 함수.
- 줄 단위: % = 원물 합계 대비 비율, kg = 1회 기준 무게 × 배수. 한 버전에 섞이면 저장 막고 질문.
- 수율 스위치 하나 (회사 스위치 폐지 → 버전에 '처리 전후 무게' 답이 있으면 그대로 적용).
- 숨길 기존 칸(지우지 않음, 고급 보기): 수율조정 중량 · 보정배합(물 뺀 %) · 기준 원물 합계 · 기준 원물 kg — 답에서 자동 계산.

### 5-3. 버전
- 승인 버전 잠금. 고치려면 '새 버전 만들기' (이전 원료·공정 지정·배율 복사) → 수정 → 시험 계산 → 승인.
- 생산은 승인 버전만. 이미 만든 배치·기록은 그때 버전 그대로 (흐름도도 버전별).
- 생산 중지 제품: 생산 목록 제외, 이력 보존.

## 6. 3층 하루 생산 · 현장

- 입력: 날짜 · 제품 · 총량 (또는 '기준 배합 N번'). 같은 제품 한 줄 (#598).
- 회차 = max(BOM 1회 기준, 설비 용량 제한) 으로 나눔 — 설비 용량이 작으면 회차가 늘어난다.
- 화면 역할: **BOM = 생산 구조(흐름도)** · **오늘 생산 = 물량 적용한 배정·회차·시간표** · **태블릿 = 내 공정 오늘 작업 순서**.
- 기록 값마다 **초안 / 확인됨 / 수정됨** (누가·언제). 측정해야만 아는 값(품온·금속검출 결과 등)은 초안을 만들지 않음.
- 정상이면 회차 묶음 한 번 확인, 다르면 그 칸만. 작업 끝나고 몰아서 확인 가능 (작업 중 반복 클릭 없음).

## 7. 초기 세팅 마법사 + 준비 점검표

```
① 업종 → ② 공정·한계기준 → ③ 설비(대수·용량·평상값·운전 방식·공유) → ④ 공장 시작시각·공통 공정
→ ⑤ 공정 흐름 틀 → ⑥ 원료 기본값(불림 배율·물) → ⑦ 제품 + 품목제조보고 올리기
→ ⑧ 원료별 질문 2개 → ⑨ 시험 생산 확인 → ⑩ 준비 점검표
```
- 업종 틀로 ②③⑤ 의 초안을 미리 채움 (떡류 틀 = 회사 데이터가 아니라 업종 데이터 — 코드 분기 없음).
