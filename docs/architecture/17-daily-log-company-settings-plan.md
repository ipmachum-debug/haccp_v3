## 6. 결정 필요

1. **온습도 무작위 표시 29건·자동 생성 116건** — 서버에 `auto_randomize_daily.cjs` 크론이 남아 있는지 Codex 읽기 확인(crontab, /var/log/haccp/auto_randomize.log). 남아 있으면 정지 여부. 해당 승인 기록에 '정정 필요' 표시·정정 문서를 만들지(자동 수정은 하지 않음).
2. **승인 기록 인쇄** — PR-A 의 ℃ 칸·원문 기준/조치를 과거 승인 기록 인쇄에도 보일지, 승인 기록은 지금 인쇄 그대로 고정할지.
3. **단지 사업장 id 1·2 혼재** — 같은 사업장인지. `unique_key` 의 사업장 범위가 이 답에 달려 있다.
4. **문구 기준** — 새 일지 질문은 원본 PDF 문구(2절 '원본' 열)로 맞추는 것이 맞는지. 저장 기록 계열(띄어쓰기·'원·부재료')과 다르다.
