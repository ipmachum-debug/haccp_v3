# 1. 제품 소개

## HACCPONE이란?

HACCPONE은 식품 제조업체를 위한 **올인원 클라우드 플랫폼**입니다.

생산관리, HACCP 기록, 재고관리, LOT 추적, 회계까지 — 기존에 엑셀, 수기 기록, 별도 회계 프로그램으로 나뉘어 관리하던 모든 업무를 **하나의 시스템**으로 통합합니다.

```
┌──────────────────────────────────────────────────┐
│                  HACCPONE                        │
│                                                  │
│   생산관리 ←→ HACCP 기록 ←→ 재고관리            │
│      ↕            ↕            ↕                 │
│   LOT 추적 ←→ 회계 연동 ←→ AI 분석              │
│                                                  │
│         모든 데이터가 자동으로 연결됩니다         │
└──────────────────────────────────────────────────┘
```

### 핵심 가치

| 문제 | HACCPONE의 해결 |
|------|----------------|
| 생산 데이터가 여러 엑셀 파일에 분산 | 하나의 대시보드에서 실시간 관리 |
| HACCP 체크리스트를 수기로 작성 | 디지털 기록 + 자동 저장 + 즉시 출력 |
| 재고와 생산 기록이 분리되어 불일치 | 생산하면 재고가 자동으로 차감/생성 |
| LOT 추적이 불가능 | 원료 입고 → 생산 → 출하까지 전 과정 추적 |
| 회계를 별도 프로그램에서 처리 | 매입/매출 자동 분개 + 재무제표 생성 |

# 2. 왜 HACCPONE인가

## 경쟁 우위 5가지

### 1. 유일한 HACCP + 회계 통합 플랫폼

다른 HACCP 소프트웨어는 생산/품질 관리만 합니다. 회계를 위해 별도 프로그램(이카운트, 더존 등)을 사용해야 하죠.

HACCPONE은 **매입/매출이 발생하면 회계 전표가 자동 생성**됩니다.
- 매입 확정 → 차변: 원재료 + 부가세 / 대변: 외상매입금
- 매출 확정 → 차변: 외상매출금 / 대변: 매출 + 매출원가
- 은행 거래 → 자동 매칭 + 분개

### 2. AI 규칙엔진 (22개 자동 감시 규칙)

사람이 놓치는 것을 AI가 24시간 감시합니다.

| 카테고리 | 감시 내용 |
|---------|----------|
| **기록 누락** | 일일 체크리스트, CCP 기록, 위생점검, 출하검사 누락 자동 감지 |
| **이탈 감지** | CCP 온도/시간/압력 이탈, 금속검출 이상, 수율 급락 감지 |
| **기한 관리** | 장비 교정 마감, 서류 검토 기한, 교육 일정, LOT 유효기한 경고 |
| **패턴 분석** | 반복 일탈 패턴 감지 → 근본 원인 분석 추천 |

### 3. 생산 → 재고 → 회계: 수기 입력 제로

```
원료 입고         →  재고 자동 증가  →  매입 전표 자동 생성
    ↓
배치 생산 시작    →  원료 자동 차감  →  원가 자동 계산
    ↓
생산 완료         →  제품 재고 증가  →  원가 전표 생성
    ↓
출하 (매출)       →  제품 재고 감소  →  매출 전표 + 원가 인식
```

한 번의 입력으로 재고, 원가, 회계가 동시에 처리됩니다.

### 4. HACCP 심사 대비 완벽 문서화

- 20종 이상의 HACCP 체크리스트 양식 내장
- CCP 기록, 일일점검, 주간점검, 월간점검 자동 저장
- **심사 자료를 버튼 하나로 PDF/Excel 출력**
- 전자 서명 + 승인 이력 자동 기록

### 5. 30분 만에 시작, 교육 불필요

- 회원가입 → 초기 설정 → 바로 사용 (30분)
- 기존 엑셀 데이터 마이그레이션 지원
- 직관적인 UI로 별도 교육 없이 현장 투입 가능
- 모바일에서도 동일하게 사용 가능

# 4. 시작하기

## 4.1 회원가입

1. **haccpone.com** 접속
2. 우측 상단 **[무료 체험 시작]** 클릭
3. 회원 유형 선택
   - **클라이언트 관리자**: 새로운 회사로 가입 (회사명, 사업자등록번호 입력)
   - **직원**: 기존 회사에 소속되어 가입 (소속 회사 선택)
4. 이메일, 비밀번호(8자 이상), 이름 입력
5. **[가입하기]** 클릭

> 관리자 가입 후 승인이 완료되면 로그인할 수 있습니다.

## 4.2 첫 로그인 후 초기 설정

### 순서 1: 마스터 데이터 등록

| 순서 | 메뉴 | 등록 내용 |
|-----|------|----------|
| 1 | 마스터 데이터 → 원재료 | 사용하는 원재료 등록 |
| 2 | 마스터 데이터 → 제품 | 생산하는 제품 등록 |
| 3 | 거래처 관리 | 공급업체, 고객사 등록 |
| 4 | 제조기준관리 → 레시피 | 제품별 BOM(원재료 배합 비율) 등록 |

> 기존 엑셀 데이터가 있다면 **엑셀 데이터 임포트** 기능으로 일괄 등록할 수 있습니다.

### 순서 2: HACCP 설정

| 순서 | 메뉴 | 설정 내용 |
|-----|------|----------|
| 1 | CCP 관리 → CCP 한계 설정 | CCP 포인트별 허용 범위 설정 |
| 2 | HACCP 체크리스트 → 템플릿 | 사용할 체크리스트 양식 선택/생성 |
| 3 | 알림 관리 → 설정 | 알림 규칙 설정 (이탈 시 즉시 알림 등) |

### 순서 3: 사용자 초대

**시스템 관리 → 사용자 관리 → [사용자 초대]**

| 역할 | 권한 | 적합한 대상 |
|-----|------|-----------|
| 관리자 (admin) | 모든 기능 접근 | 대표, 공장장 |
| 검사원 (inspector) | 품질/검사/HACCP 기록 | QC 담당자 |
| 작업자 (worker) | 생산/체크리스트 기록 | 현장 작업자 |
| 모니터 (monitor) | 조회 전용 + 승인 | 품질관리 팀장 |
| 회계 (accountant) | 회계/재고 + 조회 | 경리 담당 |

## 5.2 배치 생산관리

**경로**: HACCP 탭 → 생산관리

배치(Batch) 단위로 제품 생산을 관리합니다.

### 배치 생산 흐름

```
1. 배치 생성     →  제품, 목표 생산량, 생산 일자 입력
       ↓
2. 원료 투입     →  레시피 기반 자동 계산 / 수동 조정
       ↓              (재고에서 자동 차감)
3. 생산 진행     →  진행률 업데이트, CCP 기록 연결
       ↓
4. 생산 완료     →  실제 생산량 입력
       ↓              (제품 재고에 자동 반영)
5. 품질 확인     →  검사 결과 연결, 승인 처리
```

### 주요 기능

| 기능 | 설명 |
|------|------|
| **배치 생성** | 단건 생성 또는 일괄(Bulk) 생성 |
| **배치 상세** | 투입 원료, 생산량, CCP 기록, 검사 결과 통합 조회 |
| **배치 스케줄** | 캘린더 뷰로 생산 일정 관리 |
| **생산 일보** | 일별 생산 현황 요약 리포트 |
| **생산 효율** | OEE, 수율 분석, 자원 효율 분석 |
| **배치 원가** | 배치별 원가 분석 (원재료비, 노무비, 경비) |
| **파이프라인** | 진행 중인 배치를 시각적으로 모니터링 |

### 사용 방법: 새 배치 생성

1. **생산관리** 메뉴 클릭
2. **[새 배치 생성]** 버튼 클릭
3. 필수 정보 입력:
   - 생산할 **제품** 선택
   - **목표 생산량** 입력
   - **생산 예정일** 선택
4. **원료 투입**: 레시피가 등록된 제품이면 자동으로 원료가 계산됩니다
5. **[저장]** → 배치가 "대기" 상태로 생성
6. **[생산 시작]** → 상태가 "생산중"으로 변경, 원료 재고 차감
7. 생산 완료 시 **[생산 완료]** → 제품 재고 증가

## 5.3 HACCP 모니터링

**경로**: HACCP 탭 → 20개 이상의 체크리스트 양식

HACCPONE은 HACCP 인증에 필요한 **20종 이상의 기록 양식**을 제공합니다.

### 제공 체크리스트 목록

| 분류 | 체크리스트 |
|------|-----------|
| **일상 점검** | 개인위생점검, 작업장위생점검, 온습도점검, 조도점검 |
| **설비 관리** | 장비세척기록, 장비검사, 장비이력관리, 에어컴프레서 점검/정비 |
| **수질 관리** | 수질검사, 용수사용점검, 용수관리점검 |
| **위생 검사** | 위생시설점검, 표면오염도검사, 부유균검사 |
| **입출고** | 원료입고검사, 출하검사, 포장보관기록 |
| **품질** | 중량품질검사, 제품검사성적서, 제품시험일지, 완제품점검 |
| **특수** | 이물질관리, 냉장냉동점검, 차량온도점검, 폐기물관리 |
| **CAPA** | 부적합제품관리, 시정조치(CAPA), 소비자불만 |
| **교육/감사** | 교육훈련기록, 내부감사, HACCP검증 |

### 사용 방법

1. 해당 체크리스트 메뉴 진입
2. **[새 기록]** 클릭
3. 항목별 점검 결과 입력 (적합/부적합, 수치 입력 등)
4. 부적합 발견 시 **시정조치** 내용 기록
5. **[저장]** → 자동으로 날짜/시간/작성자 기록
6. 관리자/검사원이 **[승인]** 처리

> 모든 기록은 자동 저장되며, HACCP 인증 심사 시 **즉시 PDF로 출력**할 수 있습니다.

## 5.4 CCP 관리

**경로**: HACCP 탭 → CCP 관리

CCP(Critical Control Point, 중요관리점)를 실시간으로 모니터링합니다.

### CCP 설정

1. **CCP 한계 설정** (quality/ccp-limits)에서 각 CCP의 허용 범위를 설정
   - 예: CCP-01 살균온도 → 하한 83°C / 상한 90°C
   - 예: CCP-02 금속검출기 → 적합/부적합
2. **제품-CCP 매핑**에서 어떤 제품에 어떤 CCP가 적용되는지 설정

### CCP 기록

1. CCP 관리 메뉴 진입
2. 해당 CCP 포인트 선택
3. **측정값** 입력 (온도, 시간, 압력 등)
4. 설정된 범위를 벗어나면 **자동으로 이탈 경고** 발생
5. 이탈 시 **시정조치** 기록 필수

### CCP 대시보드 기능

| 기능 | 설명 |
|------|------|
| **실시간 현황** | 모든 CCP의 현재 상태 (정상/이탈) |
| **CCP 캘린더** | 날짜별 CCP 점검 이력 |
| **이탈 대시보드** | 이탈 건수 추이, 유형별 분석 |
| **통계** | CCP별 준수율, 이탈 빈도 |

  차변) 외상매출금 (총액)

  차변) 매출원가 (원가)

# 8. 자주 묻는 질문

### Q. 도입까지 얼마나 걸리나요?

초기 설정은 **30분 내로 완료**됩니다. 기존 엑셀 데이터가 있다면 마이그레이션도 지원해 드립니다. 대부분의 고객님이 **당일 바로 사용을 시작**하십니다.

### Q. 직원들이 사용하기 어렵지 않나요?

HACCPONE은 **별도 교육 없이도 바로 사용**할 수 있도록 직관적인 UI로 설계되었습니다. 모바일에서도 동일하게 사용할 수 있습니다.

### Q. 기존에 사용하던 엑셀 데이터는 어떻게 하나요?

품목 마스터, 거래처 정보, 재고 데이터 등 기존 엑셀 데이터를 **시스템으로 마이그레이션하는 것을 도와드립니다.**

### Q. HACCP 인증 심사에 도움이 되나요?

네, HACCPONE에서 기록되는 모든 HACCP 데이터와 체크리스트는 **인증 심사에 필요한 형식으로 자동 출력**됩니다.

### Q. 무료 체험 기간에 제한되는 기능이 있나요?

**없습니다.** 30일 무료 체험 기간 동안 선택하신 요금제의 모든 기능을 제한 없이 사용할 수 있습니다.

### Q. 데이터 보안은 어떻게 되나요?

- **멀티테넌트 격리**: 각 고객의 데이터는 완전히 분리되어 저장됩니다
- **SSL/HTTPS**: 모든 데이터 전송 구간 암호화
- **자동 백업**: 매일 새벽 자동 백업 (Standard: 30일 보관, Enterprise: 무제한)
- **접근 제어**: 역할 기반 권한 관리 (RBAC)
- **감사 로그**: 모든 주요 행위 기록

### Q. 기존 HACCP 소프트웨어에서 전환 가능한가요?

네, 기존 시스템의 데이터를 엑셀로 내보낸 후 HACCPONE으로 임포트할 수 있습니다. 전환 과정에서 기술 지원을 제공합니다.
